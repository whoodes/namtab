## Research method and limits

Official product/project documentation and primary technical references were retrieved on 2026-10-15 through web browsing. Findings below are documentation observations, not hands-on verification. Most URLs track mutable documentation or a main branch; no immutable upstream commit or complete dependency closure was established. Recheck and pin specific versions before implementation or making compatibility/security claims. Official source files were read through browser tools; no software/source tree was downloaded into the VM, installed, built or executed.

The first design phase began with an empty directory. The prior continuation read ten documents and expanded the set to thirteen. This dual-frontend continuation read all thirteen, rechecked applicable ancestor/project instructions (none found), and researched the alternatives below. No private session storage or credentials were inspected. The current recommended baseline is in [10](../architecture/10-recommended-baseline-and-adrs.md), its shared human contract in [11](../ux/11-human-experience-spec.md) and [13](../ux/13-dual-frontend-and-host-tui.md), and its falsifiable engineering order in [12](../engineering/12-prototype-plan.md). [14–17](../engineering/14-repository-and-engineering-practices.md) add repository/dependency/test and bounded-engine detail; all infrastructure remains proposed.
