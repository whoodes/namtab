# Isolated headless H0 write proof

[Admitted profile and limits](../../docs/engineering/h0-headless-write-experiment.md). The Rust implementation is in `crates/service/src/h0_write/`, deliberately separate from the historical MK1 broker and finite JS model. No listening socket or user session is used. Two scripted Unix socket-pair clients run on separate handler threads, bound to supervisor-issued endpoint handles, sharing exactly one fresh PTY/context/attempt. They are not model agents.

Use the [canonical reproduction commands](../../docs/engineering/h0-headless-write-experiment.md#reproduce); no installation or external service is needed on the prepared checkout.

`make foundation-verify` builds/runs both the existing MK1 journeys and this distinct probe/comparison. The driver exclusively creates its artifact/workspace paths, clears the Bash environment/startup/history, invokes only synthetic builtins, reaps its owned child and closes its endpoint pairs/worker. Failure also drops these owned handles. It never removes old artifacts or attaches to a named user socket. Synthetic output is explicitly retained for this test; ordinary output capture remains off.

The real fixture checks printable text and logical Enter; A→B transfer with stale queued bytes, same sequence1 in separate namespaces, original receipt lookup after supervisor reconnect, and a real DSR query/reply generated by the existing owned worker. PTY stdout/stderr are merged. Literal expected markers show this fixture's behavior; they do not establish arbitrary shell-command attribution or authenticated completion. Observation binds the worker's last reduced cut, not proof the kernel/application has no unread output.

`tests.rs` separately injects write results and withholds completion after a call; it challenges all bound fields, authority/connection/deadline changes, quotas, exact prefix/unknown/zero, reply ordering, duplicate/misattributed completions and actual mutex transfer/dispatch races. These tests run real Rust control code with a call spy; they do not inject actual kernel partial writes, prove Rust memory safety or model arbitrary kernel interleavings. The real PTY probe reports only its actually observed full writes; no forced kernel-partial claim.

`compare-model.mjs` maps three real receipts to the independent finite JS model: A's first full operation, A's queued operation fenced by transfer, B's first full operation. Printable payload lengths are projected to three synthetic bytes, A runtime sequence3 maps to model sequence2, and the runtime atomic assignment/writer transfer maps to two ordered model transitions. Other real Enter/reconnect/reply operations, observation changes, authentication, wall time, suffix/re-arm, storage, OS effects and concurrent traces are **excluded**, not silently equated. The existing model auditor checks those model transitions. Context/task digests are independently recomputed and the exact one-time DSR0 reply is checked. Intentional manifest/reply/stale-call/cross-context/false-full report corruptions must be rejected; this is a small refinement challenge, not a bisimulation or universal runtime conformance proof.

Reports bind an exact immutable context digest of prelaunch executable/schema hash observations, explicit environment/argv/workspace/profile and a fixed task digest. They are local provenance observations, not hostile-same-UID executable attestation. Capture-off receipts are RAM-only, no crash-safe commit/restore; restart requires a new epoch/session. Partial/unknown completion permanently fences every byte lane in this session. There is no suffix retry, automatic retransmit, in-place re-arm, model provider, GUI, capacity/performance qualification or broad H0 acceptance.
