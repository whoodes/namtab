              Keyboard help and geometry
              

                Keys go to this shell only while the keyboard field is focused.
                Tab and application shortcuts go to the terminal. Ctrl+G then
                Escape returns to session controls; Ctrl+G twice sends literal
                Ctrl+G. Unknown prefix keys pause typing. Select screen text
                outside this field and Ctrl+C to copy; Ctrl+C inside goes to the
                application. Ctrl+V pastes only when the application enables
                bracketed paste. Refusal or uncertain delivery pauses all typing
                until explicit inspection and Take input.
